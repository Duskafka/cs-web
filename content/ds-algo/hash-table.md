# 해시 테이블

해시 함수가 키를 정수로 바꾸고, 그 정수를 버킷 배열의 인덱스로 쓴다. 평균 조회·삽입·삭제가 모두 `O(1)` 이다.

## 충돌 처리

서로 다른 키가 같은 버킷으로 가는 **충돌**은 피할 수 없다.

| 방식 | 설명 | 특징 |
| --- | --- | --- |
| 체이닝 | 버킷마다 연결 리스트 | 구현이 단순, 포인터 오버헤드 |
| 개방 주소법 | 다음 빈 칸 탐색 | 캐시 지역성 우수, 삭제가 까다로움 |

Java 의 `HashMap` 은 한 버킷의 체인이 8개를 넘으면 이진 트리로 바꿔 최악의 경우를 `O(log n)` 으로 막는다.

## 연결

- 조회는 빠르지만 순서가 없으므로 범위 질의에는 이진 트리가 낫다.
- 캐싱 전략의 저장소와 인증과 인가의 세션 조회가 이 구조 위에 서 있다.
- 동적 계획법의 메모이제이션 테이블로도 자주 쓴다.

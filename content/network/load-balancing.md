# 로드 밸런싱

## 분배 알고리즘

- **라운드 로빈**: 순서대로. [[CPU 스케줄링]]의 라운드 로빈과 같은 아이디어다.
- **최소 연결**: 현재 연결이 가장 적은 서버로.
- **해시 기반**: 클라이언트 IP 나 세션 키를 해싱해 항상 같은 서버로 보낸다. 내부적으로 [[해시 테이블]]과 같은 원리이며, 서버 수가 바뀌어도 재배치를 최소화하려면 **일관된 해싱**을 쓴다.

## L4 와 L7

L4 는 IP/포트만 보고 넘긴다. 빠르지만 내용을 모른다. L7 은 [[HTTP]] 경로나 헤더를 보고 라우팅할 수 있어 [[마이크로서비스 아키텍처]]의 API 게이트웨이 역할까지 겸한다. 대신 [[HTTPS와 TLS]]를 종료해야 하므로 인증서 관리 지점이 된다.

## 전제 조건

무상태 서버여야 아무 서버로나 보낼 수 있다. 세션을 서버 메모리에 두면 이 전제가 깨지므로 Redis 같은 외부 저장소로 빼는데, 이는 [[캐싱 전략]]과 맞닿는다.

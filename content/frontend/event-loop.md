# 이벤트 루프

자바스크립트는 [[스레드]] 하나로 돌아간다. 그런데도 동시성처럼 보이는 이유는, 오래 걸리는 일을 브라우저(또는 libuv)에 맡기고 콜백만 큐로 돌려받기 때문이다.

## 실행 순서

콜 스택이 비면 루프가 다음을 반복한다.

1. **마이크로태스크 큐**를 **전부** 비운다 (`Promise.then`, `queueMicrotask`).
2. 매크로태스크를 **하나** 꺼내 실행한다 (`setTimeout`, I/O, 이벤트 핸들러).
3. 필요하면 렌더링한다 (`requestAnimationFrame`).

```js
console.log('1');
setTimeout(() => console.log('4'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('2');
// 1 2 3 4
```

마이크로태스크에서 또 마이크로태스크를 만들면 렌더링이 영원히 밀린다.

## 연결

- 무거운 동기 작업이 스택을 점유하면 [[브라우저 렌더링 파이프라인]]이 멈춰 화면이 얼어붙는다.
- OS 의 [[컨텍스트 스위칭]] 비용을 피하려는 비동기 I/O 모델과 뿌리가 같다.
- 진짜 병렬 연산이 필요하면 Web Worker 로 [[프로세스]]에 준하는 격리된 실행 환경을 만든다.

# CPU 스케줄링

## 대표 정책

- **FCFS**: 먼저 온 순서. 긴 작업 하나가 뒤를 다 막는 convoy effect 가 있다.
- **SJF**: 실행 시간이 짧은 것부터. 평균 대기 시간이 최소지만 실행 시간을 미리 알 수 없다.
- **라운드 로빈**: 타임 퀀텀만큼 돌아가며 실행. 응답성이 좋아 대화형 시스템의 기본이다.
- **다단계 피드백 큐**: 우선순위 큐를 여러 층 두고 CPU 를 많이 쓴 작업을 아래로 내린다. 리눅스 CFS 를 포함한 현대 스케줄러의 뼈대다.

## 절충점

퀀텀을 줄이면 응답 시간은 좋아지지만 [[컨텍스트 스위칭]] 횟수가 늘어 처리량이 떨어진다.

## 연결

- 스케줄링 단위는 대부분의 현대 OS 에서 [[프로세스]]가 아니라 [[스레드]]다.
- 요청을 서버에 배분하는 [[로드 밸런싱]]도 라운드 로빈, 최소 연결 같은 같은 아이디어를 쓴다.
- 부팅 직후 스케줄러가 어떻게 초기화되는지는 [[운영체제 부팅 과정]]에서 다룬다.

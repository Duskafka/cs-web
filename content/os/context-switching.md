# 컨텍스트 스위칭

CPU 가 실행 중인 [[프로세스]]나 [[스레드]]를 바꿀 때, 현재 상태(레지스터, 프로그램 카운터, 스택 포인터)를 PCB 에 저장하고 다음 대상의 상태를 복원한다.

## 비용

순수한 저장·복원 시간은 마이크로초 단위지만, 진짜 비용은 **캐시와 TLB 가 무효화되는 것**이다. 프로세스 전환은 페이지 테이블까지 바꾸므로 TLB 를 비워야 하고, 이후 한동안 [[가상 메모리]] 주소 변환이 느려진다. 스레드 전환은 주소 공간이 같아 이 비용이 없다.

## 연결

- 전환 빈도는 [[CPU 스케줄링]]의 타임 퀀텀이 결정한다. 퀀텀이 짧으면 응답성은 좋아지지만 오버헤드가 커진다.
- 요청마다 실행 흐름을 새로 만들지 않고 미리 만들어 돌려쓰는 이유가 이 비용이며, [[커넥션 풀]]이 같은 발상이다.

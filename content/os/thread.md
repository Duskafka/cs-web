# 스레드

스레드는 프로세스 안의 실행 흐름이다. 스택과 레지스터, 프로그램 카운터만 따로 갖고 코드·데이터·힙은 형제 스레드와 **공유**한다.

## 가벼움의 대가

생성과 전환이 프로세스보다 훨씬 싸다. 대신 공유 자원에 여러 스레드가 동시에 접근하면 **경쟁 조건(race condition)** 이 발생한다. 뮤텍스나 세마포어로 임계 구역을 보호해야 하는데, 잠금 순서를 잘못 잡으면 그대로 데드락이다.

```java
private final Object lock = new Object();

void increment() {
    synchronized (lock) {
        counter++;   // 임계 구역
    }
}
```

## 연결

- 스레드 간 전환도 컨텍스트 스위칭이지만 주소 공간을 안 바꿔서 훨씬 저렴하다.
- 요청을 처리하는 스레드 수와 DB 연결 수를 함께 맞추는 문제가 커넥션 풀이다.
- 데이터베이스의 동시 트랜잭션 제어도 같은 문제를 다루며 격리 수준으로 정리된다.

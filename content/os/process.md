# 프로세스

프로세스는 **실행 중인 프로그램**이다. 코드(text), 데이터, 힙, 스택으로 나뉜 독립적인 주소 공간을 갖고, 커널은 이를 PCB(Process Control Block)로 관리한다.

## 독립성의 값과 대가

주소 공간이 분리되어 있어 한 프로세스가 죽어도 다른 프로세스에 영향이 없다. 대신 데이터를 주고받으려면 파이프, 공유 메모리, 소켓 같은 **IPC** 가 필요하고 생성 비용도 크다. 그래서 같은 일을 더 싸게 하려고 [[스레드]]를 쓴다.

## 상태 전이

`생성 → 준비 → 실행 → 대기 → 종료` 를 오간다. 준비와 실행 사이를 오갈 때마다 [[컨텍스트 스위칭]]이 일어난다. 어떤 프로세스를 실행할지는 [[CPU 스케줄링]]이 결정한다.

## 연결

- 주소 공간의 환상은 [[가상 메모리]]가 만들어낸다.
- 여러 프로세스가 자원을 물고 늘어지면 [[데드락]]이 생긴다.
- 브라우저는 탭마다 프로세스를 나누는데, 그 구조는 [[브라우저 렌더링 파이프라인]]에서 다룬다.
